## Smart Online Status Guide

### What Changed?
Previously, the bot could be set to "always online" which kept a persistent presence.
Now, the bot intelligently manages presence:

**Default Behavior (Smart Mode):**
- Shows ONLINE when responding to messages
- Auto-sets OFFLINE after 2 minutes of no activity
- Users see realistic, human-like presence patterns

**When to Use Always-On:**
```
.online on     — Enables always-online for constant availability
.online off    — Reverts to smart (activity-based) presence
```

### Why Smart Online?
1. **Privacy**: Your bot doesn't constantly broadcast presence
2. **Battery**: Less constant keepalive = lower power usage
3. **Realistic**: Matches human behavior patterns
4. **Professional**: Modern bots don't stay artificially online

## Error Handling

If you see "ENGINE_URL not configured":
1. Go to Vercel project settings
2. Add Environment Variables:
   - ENGINE_URL = https://whatsbot.hostify.co.zw
   - ENGINE_API_KEY = (your key)
3. Redeploy the project
